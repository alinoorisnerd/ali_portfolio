04 · Featured project

modRUN

An AI-driven chip design tool for macOS

modRUN automates the full chip design flow, from Verilog RTL and testbenches through synthesis, timing analysis and place-and-route to final layout inspection. An LLM writes and debugs RTL, a reinforcement learning agent optimizes placement, and every model runs on the Apple Neural Engine, so proprietary designs never leave the laptop.
