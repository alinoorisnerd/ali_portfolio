Project · Oct 2026 – Present

modRUN

An AI-driven chip design tool for macOS that runs the full flow, from Verilog to layout inspection, completely offline.

Role: Builder Stack: Swift, Apple Neural Engine, LLMs, Reinforcement learning, Verilog, TCL Status: In development
Problem

A chip design cycle can take about a year, with slow manual hand-offs between every tool in the flow.

Approach

An LLM writes and debugs RTL, a reinforcement learning agent optimizes placement, and each stage feeds its results into the next.

Why on-device

Every model runs on the Apple Neural Engine, so proprietary designs stay air-gapped on the engineer’s laptop.

The flow

Six stages, one app

Click a stage to see what modRUN does there.

RTL generation

An on-device LLM turns a design spec into Verilog, then reads compiler and lint errors back to fix its own code.

Architecture

How it fits together

1 · Interface

Native macOS app

Written in Swift. The engineer describes the design, watches each stage run and reviews the results.

2 · Intelligence

On-device models

An LLM for RTL and testbenches and an RL agent for placement, both running on the Apple Neural Engine.

3 · Flow

Design stages

Synthesis, timing analysis, place-and-route and inspection, with results looping back so the models can fix problems.
